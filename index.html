تحليل الأدلة

مراجعة النصوص والصور والمواد التي يحق للمستخدم الوصول إليها، مع إظهار مواضع عدم اليقين والسياق الناقص.

تقارير قابلة للمراجعة

عرض روابط المحتوى، والتصنيفات المحتملة، وشرح الأدلة، والرجوع إلى السياسات المنشورة.

قرار بشري مستقل

النتائج استشارية وليست قرارًا من Meta، ولا يرسل المشروع بلاغات تلقائية ولا يضمن وصولًا إلى صفحات مقيدة.

الخصوصية والشفافية

لا يطلب موقعنا التعريفي كلمات مرور Facebook أو رموز جلساته. استخدام أي تكامل رسمي أو خدمة ذكاء اصطناعي يخضع للإعدادات والصلاحيات المتاحة وموافقة المستخدم اللازمة.

حذاري مشروع مستقل وغير تابع لشركة Meta أو Facebook أو Google. ذكر الأسماء والسياسات لأغراض وصفية فقط، ولا يشير إلى شراكة أو اعتماد رسمي.
