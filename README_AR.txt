موقع حذاري للنشر على GitHub Pages

1. افتح ملفات HTML الأربعة واستبدل CONTACT_EMAIL_HERE ببريد التواصل الصحيح الذي تملكه.
2. ارفع الملفات الأربعة في جذر مستودع GitHub عام.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. تحقق من فتح / و /privacy.html و /deletion.html قبل استخدام الموقع في Meta.
5. لا ترفع مفاتيح API أو قاعدة بيانات أو كلمات مرور إلى مستودع عام.

الملفات مستقلة: تم تضمين CSS داخل كل صفحة لتسهيل الرفع من الهاتف.
هذه صفحات تعريفية لا تؤكد وجود شركة مسجلة، ولا تحل محل مستندات التحقق التي قد تطلبها Meta.
